Full Project Description

Production website বানাতে backend, database, role, SMS, live monitoring plan.

Core modules

1. Member management: 26 jon member, phone, room/status, active/inactive, minimum meal rule, monthly opening balance.

2. Daily meal board: date-wise breakfast/lunch/dinner, F shortcut, guest meal, staying flag, lock-after-day-end option.

3. Payment ledger: 10 tarik 1000, 20 tarik 1000, 30 tarik 500, extra collection, refund, due history.

4. Expense ledger: food/bazar/chaul meal-rate category; wifi/gas/current/khala/extra shared category; notes and receipt photo.

5. Bazar duty: every 4 days schedule, 2 members, advance taka, shopping list, spent, return taka, manager approval.

6. Reports: meal rate, total meal, billable meal, guest meal, other cost/member, total bill, joma, mess pabe/member pabe.

Calculation model

Actual meal = breakfast*0.5 + lunch + dinner. Food cost = food + rice + bazar items. Meal rate = food cost / total actual meal. Billable meal = max(actual meal, 50), but zero-meal member = max(25, guest meal). Guest meal fixed minimum-er upor add hobe.

Other cost/member = shared expenses / active members. Member total = billable meal*meal rate + other cost/member. Settlement = total bill - total joma.

Production stack

Frontend: Next.js/React. Backend: Supabase or Firebase for live database/auth. Storage: receipt and board photo upload. Hosting: Vercel/Netlify. Database tables: members, meal_entries, payments, expenses, bazar_duties, shopping_items, monthly_settings, audit_logs.

Authentication and roles

Prototype-e Gmail-format login local browser-e save hoy. Real secure system-er jonno Firebase Auth Google Sign-In ba Supabase Google OAuth lagbe. Server-side rule hobe: only manager can insert/update/delete meal, payment, expense, bazar duty, member, and role records. Members can only read own data and final reports.

WhatsApp/SMS automation

Static website theke direct automatic WhatsApp send kora jay na; browser security and WhatsApp policy block kore. Best options: WhatsApp Cloud API/Twilio backend, ba click-to-send link. Ei prototype click-to-send link banay. Production backend scheduled reminder pathabe: installment due, bazar duty, month-end settlement.

Roles

Manager full access, assistant manager expense/payment entry, member own meal/payment/report view, auditor read-only month-end check.
